# Talkbook 技术基线

## 技术方向

### 前端
- 首发平台：微信小程序
- 开发方案：uni-app
- 原因：启动快、开发成本低、适合快速验证 MVP

### 后端
- 方案：Node.js + TypeScript
- 责任：统一承接登录、会话、语音识别、大模型编排、支付、书稿生成

### 第三方能力
- 语音识别：讯飞 / 百度
- 大模型：豆包优先，保留可切换能力
- 支付：微信支付
- 文件存储：COS / OSS

## 模块划分

### 小程序端
- 首页 / 书籍类型选择
- AI 采访页
- 书稿预览页
- 用户中心
- 订单与会员页

### 服务端
- 用户与登录
- 会话与消息管理
- 音频文件上传
- ASR 抽象层
- Prompt 编排层
- 书稿生成服务
- 支付与订单服务
- 内容审核与风控

## 当前不立即编码的原因

在真正生成代码之前，必须先定清楚：

- 页面范围
- 数据模型
- 外部服务选型
- Prompt 结构
- 计费方式
- 风控与版权边界

否则会过早进入“写了很多代码，但方向不稳”的状态。

## 下一步真正编码时的建议顺序

1. 初始化 uni-app 小程序工程
2. 初始化 Node.js 服务端工程
3. 建立共享接口文档
4. 打通语音上传与转写
5. 打通 AI 多轮提问
6. 打通成书生成
7. 最后补支付与会员
