# Talkbook 开发路线图

## Phase 0：重新启动（当前阶段）
- 清理不成熟的示例代码
- 固化产品基线与技术路线
- 明确本地开发约定
- 为正式初始化工程做准备

## Phase 1：工程初始化
- 初始化 uni-app 项目
- 初始化 Node.js + TypeScript 服务端
- 配置代码规范、环境变量、目录结构
- 建立 API 文档与基础数据模型

## Phase 2：MVP 主流程
- 书籍类型选择
- AI 引导问答
- 语音上传与转写
- 会话记录
- 书稿目录与正文生成

## Phase 3：商业化基础
- 微信支付
- 按本收费
- 会员体系
- 导出能力

## Phase 4：上线准备
- 内容审核
- 隐私政策 / 用户协议
- 数据埋点
- 灰度测试与微信审核
