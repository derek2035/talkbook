# Talkbook MVP 页面与交互说明

## 目标

把第一版真正要开发的页面、核心交互、状态流转定义清楚，避免初始化工程后反复返工。

## 页面清单

### 1. 首页 / 书籍类型页

#### 目标
让用户快速理解产品价值并开始创作。

#### 页面内容
- 产品一句话介绍
- 书籍类型卡片
- “开始创作”按钮
- 最近书稿/预览提示（若已有）

#### 用户操作
1. 进入首页
2. 选择书籍类型
3. 点击开始创作
4. 进入 AI 采访页

#### 前端状态
- `selectedBookType`
- `bookCount`
- `latestBookTitle`

## 2. AI 采访页

#### 目标
通过 AI 主动提问 + 用户回答，持续采集成书素材。

#### 页面内容
- 当前书籍类型
- 当前会话标识
- AI 当前问题
- 历史对话列表
- 语音占位输入区 / 文字模拟输入区
- “我想跳过”按钮
- “生成书稿”按钮（满足最小素材量后可点击）

#### 核心交互
1. 用户在首页点击“开始创作”时创建会话
2. 进入采访页后读取当前会话详情
3. 用户先通过文字模拟回答，后续替换为真实录音上传
4. 服务端返回转写文本与下一问题
5. 对话持续累积
6. 达到最小素材量后允许生成预览

#### 前端状态
- `sessionId`
- `currentQuestion`
- `messages`
- `answerCount`
- `inputStatus`
- `canGenerate`

## 3. 书稿预览页

#### 目标
展示 AI 生成的目录、章节摘要和升级付费入口。

#### 页面内容
- 书名建议
- 一句话简介
- 章节目录
- 每章摘要
- “继续补充素材”按钮
- “完整版待解锁”提示

#### 用户操作
1. 查看目录和摘要
2. 如果内容不足，返回继续采访
3. 如果满意，等待后续完整版/支付能力接入

#### 前端状态
- `bookId`
- `outline`
- `previewStatus`
- `paymentRequired`

## 4. 我的页面

#### 目标
承接用户历史内容和商业化能力。

#### 页面内容
- 书稿列表
- 空状态提示
- 会员状态
- 后续商业化入口占位

## MVP 页面流转

```text
首页/书籍类型页
  -> AI 采访页
    -> 书稿预览页
      -> 完整版待解锁提示
      -> 或返回 AI 采访页继续补充
```

## MVP 最小可用标准

### 首页
- 能选择书籍类型并进入下一页

### AI 采访页
- 能创建会话
- 能读取当前会话
- 能提交文字模拟回答
- 能看到转写文本
- 能收到 AI 下一问
- 能跳过问题
- 达到阈值后能解锁预览按钮

### 书稿预览页
- 能看到目录和章节摘要
- 能返回采访页继续补充
- 能展示完整版待解锁提示

### 我的页面
- 能看到已生成书稿列表
- 没有内容时有空状态
