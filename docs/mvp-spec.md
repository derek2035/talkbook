# Talkbook MVP 页面与交互说明

## 目标

把第一版真正要开发的页面、核心交互、状态流转定义清楚，避免初始化工程后反复返工。

## 页面清单

### 1. 首页 / 书籍类型页

#### 目标
让用户快速理解产品价值并开始创作。

#### 页面内容
- 产品一句话介绍
- 书籍类型卡片
- “开始创作”按钮
- 最近草稿入口（若已有）

#### 用户操作
1. 进入首页
2. 选择书籍类型
3. 点击开始创作
4. 进入 AI 采访页

#### 前端状态
- `selectedBookType`
- `draftCount`
- `hasUnfinishedSession`

## 2. AI 采访页

#### 目标
通过 AI 主动提问 + 用户语音回答，持续采集成书素材。

#### 页面内容
- 当前书籍类型
- AI 当前问题
- 历史对话列表
- 录音按钮
- “我想跳过”按钮
- “生成书稿”按钮（满足最小素材量后可点击）

#### 核心交互
1. 页面加载后请求创建会话
2. 服务端返回首个问题
3. 用户按住说话或点击录音
4. 上传音频并触发转写
5. 服务端返回转写文本与下一问题
6. 对话持续累积

#### 前端状态
- `sessionId`
- `currentQuestion`
- `messages`
- `recordingStatus`
- `transcribeStatus`
- `canGenerate`

## 3. 书稿预览页

#### 目标
展示 AI 生成的目录、章节摘要和升级付费入口。

#### 页面内容
- 书名建议
- 一句话简介
- 章节目录
- 每章摘要
- “生成完整版” / “导出” / “继续补充素材”按钮

#### 用户操作
1. 查看目录和摘要
2. 如果内容不足，返回继续采访
3. 如果满意，进入支付或生成完整版

#### 前端状态
- `bookId`
- `outline`
- `previewStatus`
- `paymentRequired`

## 4. 我的页面

#### 目标
承接用户历史内容和商业化能力。

#### 页面内容
- 用户信息
- 书稿列表
- 草稿列表
- 订单记录
- 会员状态
- 版权与隐私说明入口

## MVP 页面流转

```text
首页/书籍类型页
  -> AI 采访页
    -> 书稿预览页
      -> 支付/导出
      -> 或返回 AI 采访页继续补充
```

## MVP 最小可用标准

### 首页
- 能选择书籍类型并进入下一页

### AI 采访页
- 能创建会话
- 能上传音频
- 能看到转写文本
- 能收到 AI 下一问

### 书稿预览页
- 能看到目录和章节摘要
- 能触发完整版生成或支付

### 我的页面
- 能看到已生成书稿和草稿列表
