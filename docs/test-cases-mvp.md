# Talkbook MVP 测试用例

## 1. 文档说明

### 1.1 目的

本文档用于覆盖 Talkbook 当前封版文档中的全部 MVP 需求和功能点，作为后续：

- 开发联调测试清单
- 提测前自测清单
- 验收测试清单
- 回归测试清单

### 1.2 适用范围

本文档覆盖以下文档约束下的 MVP 范围：

- `docs/product-plan.md`
- `docs/product-requirements-prd.md`
- `docs/mvp-spec.md`
- `docs/api-contract.md`
- `docs/data-model.md`

### 1.3 测试目标

- 验证首页 -> 采访页 -> 预览页 -> 我的页面主链路可用
- 验证页面交互、状态流转、接口契约、数据保存、错误处理符合文档
- 验证当前 MVP 的 mock 策略可支撑开发联调
- 验证文档中已明确“不做”的能力未被误实现为必需项

### 1.4 不在本轮测试范围

- 微信正式登录
- 真实支付回调
- 正式导出 PDF / Word
- 真实 ASR 识别服务
- 真实 LLM 生成质量评估
- 内容审核正式策略

## 2. 测试环境与前置条件

### 2.1 环境要求

- 本地仓库已按独立项目方式初始化
- 已执行 `pnpm install`
- 已执行 `pnpm typecheck`
- 已执行 `pnpm build:server`
- 服务端可在本地正常启动
- 小程序端可在本地开发环境打开

### 2.2 推荐环境

- Node.js：与仓库当前要求一致
- pnpm：与仓库 `packageManager` 一致
- 服务端地址：`http://localhost:3000`
- 小程序端：uni-app 本地开发环境

### 2.3 基础测试数据

- 书籍类型：`novel`、`autobiography`、`memoir`、`family-story`
- 模拟回答文本 A：`我最想写的是我的母亲，她总是在最困难的时候把家撑住。`
- 模拟回答文本 B：`那段故事发生在我上初中的时候，家里压力很大。`
- 模拟回答文本 C：`我最难忘的是她在深夜还陪我写作业，自己却累得睡着了。`

## 4. 测试用例

## 4.1 全局与通用能力

### TC-GLB-001 独立仓库约束验证

- 关联需求：`REQ-GLOBAL-001`
- 测试目标：验证项目作为独立仓库存在，不与其他仓库工作区混用
- 前置条件：项目位于本地目录
- 测试步骤：
  1. 进入项目根目录执行 `pwd`
  2. 执行 `git remote -v`
  3. 执行 `git status`
  4. 检查返回内容中是否出现其他项目文件
- 预期结果：
  1. 当前路径为独立的 `talkbook` 目录
  2. Git 远端指向 Talkbook 仓库
  3. `git status` 不包含其他仓库的文件

### TC-GLB-002 主链路状态定义验证

- 关联需求：`REQ-GLOBAL-002`
- 测试目标：验证系统能区分未开始、采访中、可生成预览、已生成预览
- 前置条件：服务端和前端均可运行
- 测试步骤：
  1. 首次进入首页，未创建会话
  2. 点击开始创作，创建会话但未满足预览条件
  3. 提交至少 2 次有效回答
  4. 生成书稿预览
- 预期结果：
  1. 未开始状态下，无当前会话
  2. 创建会话后进入采访中状态
  3. 达到阈值后进入可生成预览状态
  4. 生成预览后进入已生成预览状态

### TC-GLB-003 全局错误提示验证

- 关联需求：`REQ-GLOBAL-003`
- 测试目标：验证关键失败场景都有明确错误反馈
- 前置条件：服务端可手动关闭或构造异常
- 测试步骤：
  1. 关闭服务端后点击开始创作
  2. 在采访页关闭服务端后提交回答
  3. 在采访页关闭服务端后点击生成预览
  4. 恢复服务端后再次操作
- 预期结果：
  1. 首页显示创建会话失败提示
  2. 采访页显示提交失败提示
  3. 采访页显示生成预览失败提示
  4. 服务恢复后可继续正常流程

### TC-GLB-004 页面跳转路径验证

- 关联需求：`REQ-GLOBAL-004`
- 测试目标：验证页面跳转符合主链路，不出现不可理解跳转
- 前置条件：服务端正常
- 测试步骤：
  1. 从首页点击开始创作
  2. 在采访页完成回答并点击生成预览
  3. 在预览页点击继续补充素材
- 预期结果：
  1. 首页仅在用户点击按钮后跳转采访页
  2. 采访页仅在用户点击生成预览后跳转预览页
  3. 预览页能返回采访页继续补充

### TC-GLB-005 最小数据保留验证

- 关联需求：`REQ-GLOBAL-005`
- 测试目标：验证最小数据对象都能在流程中被读取
- 前置条件：完成一次完整主链路
- 测试步骤：
  1. 创建会话并提交回答
  2. 读取会话详情
  3. 生成预览并读取我的书稿列表
- 预期结果：
  1. 会话中保留书籍类型、会话 ID、问答记录
  2. 预览结果可读取
  3. 我的书稿中可见最近更新时间
