# Talkbook MVP 开发自测清单

## 1. 文档目的

本清单用于开发过程中逐项自测，目标是尽量在提交前发现问题，减少联调和提测阶段返工。

使用原则：

- 每完成一个功能模块，就执行对应模块自测
- 每次提交前，至少执行一次“核心回归清单”
- 当前清单以 MVP 范围为准，不覆盖真实支付、正式导出

## 2. 使用方式

建议按以下状态标记：

- `[ ]` 未验证
- `[x]` 已通过
- `[!]` 有问题待修复
- `[-]` 当前版本不适用

## 3. 环境自测

- [ ] 项目位于独立的 `talkbook` 仓库目录
- [ ] `pnpm install` 成功
- [ ] `pnpm typecheck` 成功
- [ ] `pnpm build:server` 成功
- [ ] 服务端可本地启动
- [ ] 小程序端可在本地开发环境打开
- [ ] 小程序端请求地址指向本地服务端

## 4. 首页自测

### 4.1 展示检查

- [ ] 首页顶部有清晰的一句话产品说明
- [ ] 首页有明确的 `微信登录` 入口
- [ ] 首页展示 4 个固定书籍类型
- [ ] 每个类型都有简短说明
- [ ] 页面默认有一个选中类型
- [ ] 已有内容时可看到最近内容提示
- [ ] 无内容时首页不会显示错误或脏状态
- [ ] 首页无无定义的左上角菜单图标
- [ ] 首页无无需求定义的 `设置` 入口
- [ ] 首页无 `查看更多类型` 入口
- [ ] 二级页面左上角为返回按钮，不是菜单图标

### 4.2 交互检查

- [ ] 点击任意书籍类型时，选中状态能正确切换
- [ ] 同一时刻只有一个书籍类型被选中
- [ ] 未登录时不能直接进入创作主链路
- [ ] 登录成功后右上角展示用户头像或昵称入口
- [ ] 点击开始创作时会发起创建会话请求
- [ ] 创建成功后会跳转采访页
- [ ] 创建失败后会停留在首页并提示错误
- [ ] 创建中按钮状态正确，避免重复点击

### 4.3 边界检查

- [ ] 服务端关闭时，首页错误提示明确
- [ ] 快速连续点击开始创作，不会创建多个异常会话
- [ ] 已有书稿数量和最近标题展示正确

## 5. 采访页自测

### 5.1 基础展示

- [ ] 页面展示当前书籍类型
- [ ] 页面展示当前会话 ID
- [ ] 页面展示当前问题
- [ ] 页面展示历史对话列表
- [ ] 页面支持 `语音播放 / 文字记录` 切换
- [ ] 每条采访记录展示时间
- [ ] 页面展示回答次数或预览解锁提示
- [ ] 页面核心文案统一为简体中文

### 5.2 会话回读

- [ ] 进入采访页时会主动读取会话详情
- [ ] 已有消息能正确回显
- [ ] 当前问题与服务端返回一致
- [ ] 回答次数与 `canGenerate` 状态恢复正确
- [ ] 会话不存在时能提示并引导返回首页

### 5.3 提交回答

- [ ] 输入文本后可提交回答
- [ ] 空文本时不可提交
- [ ] 提交中按钮状态正确
- [ ] 提交成功后用户消息会进入列表
- [ ] 提交成功后 AI 下一问会更新
- [ ] `answerCount` 会累加
- [ ] 达到阈值后 `canGenerate=true`

### 5.4 录音与分段

- [ ] 主录音按钮文案为 `开始录音`
- [ ] 点击一次 `开始录音` 后可直接进入录音界面
- [ ] 录音界面显示 `正在录音`
- [ ] 录音界面显示当前录音时长
- [ ] 录音界面可暂停录音
- [ ] 录音界面可结束录音
- [ ] 录音界面无 `完成` 按钮
- [ ] 长录音会自动切分为约 1 分钟的小音频
- [ ] 自动切分尽量避开一句话中间
- [ ] 分段结果可按 `第1段 / 第2段` 或等价形式展示
- [ ] 分段音频可单独播放并显示时长、时间
- [ ] 页面有长录音自动分段说明

### 5.5 跳过问题

- [ ] 点击跳过后可进入下一问
- [ ] 跳过后不会中断会话
- [ ] 跳过后历史消息与状态保持正确
- [ ] 连续跳过多次仍能正常推进问题

### 5.6 生成预览

- [ ] 未达到阈值时生成预览按钮不可用
- [ ] 达到阈值后生成预览按钮可用
- [ ] 点击生成预览会发起请求
- [ ] 成功后跳转到预览页
- [ ] 失败时能提示错误

### 5.7 边界与异常

- [ ] 服务端异常时提交回答有明确提示
- [ ] 服务端恢复后可再次正常提交
- [ ] 刷新或重新进入采访页后状态不丢失
- [ ] 输入超长文本时页面表现稳定
- [ ] 长录音分段异常时有明确提示

## 6. 预览页自测

### 6.1 展示检查

- [ ] 页面展示书名建议
- [ ] 页面展示一句话简介
- [ ] 页面展示章节目录
- [ ] 页面展示每章摘要
- [ ] 页面展示“完整版待解锁”提示
- [ ] 页面展示 `bookId` 或当前预览状态信息

### 6.2 交互检查

- [ ] 点击继续补充素材可返回采访页
- [ ] 返回后会话内容仍存在
- [ ] 预览生成后会写入我的书稿列表

### 6.3 空状态与异常

- [ ] 没有预览数据时页面有明确提示
- [ ] 空状态下不会出现白屏
- [ ] 预览生成失败后用户知道如何返回继续操作

## 7. 我的页面自测

### 7.1 展示检查

- [ ] 页面展示书稿数量
- [ ] 页面展示会员状态或占位文案
- [ ] 页面展示书稿列表
- [ ] 每条书稿包含标题、状态、更新时间

### 7.2 列表行为

- [ ] 最新更新的书稿排在最前
- [ ] 新生成的预览可立即出现在列表中
- [ ] 列表为空时有空状态提示

### 7.3 边界与异常

- [ ] 无任何书稿时页面展示正常
- [ ] 服务端异常时不会出现不可恢复状态

## 8. 服务端接口自测

### 8.1 创建会话

- [ ] `POST /api/v1/sessions` 可正常返回 `sessionId/bookType/firstQuestion`
- [ ] 不同请求返回不同 `sessionId`
- [ ] `bookType` 能随前端选择变化

### 8.2 获取会话详情

- [ ] `GET /api/v1/sessions/:sessionId` 返回 `status/currentQuestion/messages/canGenerate/answerCount`
- [ ] 不存在的 `sessionId` 返回明确错误

### 8.3 上传音频/模拟转写

- [ ] `POST /api/v1/sessions/:sessionId/audio` 支持 `transcript`
- [ ] 返回包含 `messageId/transcript/nextQuestion/canGenerate/answerCount`
- [ ] 不存在的 `sessionId` 返回明确错误

### 8.4 跳过问题

- [ ] `POST /api/v1/sessions/:sessionId/skip` 返回 `nextQuestion/canGenerate/skippedCount`
- [ ] 连续调用能持续推进问题

### 8.5 生成预览

- [ ] `POST /api/v1/sessions/:sessionId/generate-preview` 返回 `bookId/title/summary/outline/paymentRequired`
- [ ] 不存在的 `sessionId` 返回明确错误

### 8.6 书稿详情与列表

- [ ] `GET /api/v1/books/:bookId` 返回 `sessionId/summary/status/outline/chapters/updatedAt`
- [ ] `GET /api/v1/me/books` 返回书稿列表
- [ ] 不存在的 `bookId` 返回明确错误

## 9. 数据自测

- [ ] 会话里保留书籍类型
- [ ] 会话里保留历史问答
- [ ] 会话里保留当前问题
- [ ] 会话里保留回答次数
- [ ] 生成预览后能关联 `sessionId` 与 `bookId`
- [ ] 书稿列表能看到最近更新时间

## 11. 核心回归清单

每次提交前至少执行以下 10 项：

- [ ] 首页可正常打开
- [ ] 首页能切换书籍类型
- [ ] 首页能创建会话
- [ ] 采访页能回读当前会话
- [ ] 采访页能提交 1 次回答
- [ ] 采访页提交 2 次回答后能解锁预览
- [ ] 采访页能跳过问题
- [ ] 预览页能展示标题、简介、目录、摘要
- [ ] 我的页面能看到新生成书稿
- [ ] `pnpm typecheck` 与 `pnpm build:server` 仍然通过
