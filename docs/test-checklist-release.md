# Talkbook MVP 提测与验收清单

## 1. 文档目的

本清单用于正式提测前和验收时逐项确认，避免“功能做了，但无法稳定提测”的情况。

## 2. 提测前门槛

以下条件必须全部满足，才允许进入提测：

- [ ] 需求文档、页面说明、接口文档、数据模型、测试用例已封版
- [ ] 本次提交范围明确
- [ ] 所有 P0 功能已开发完成
- [ ] 开发已完成模块自测
- [ ] 当前版本没有阻断主链路的已知问题
- [ ] `pnpm typecheck` 通过
- [ ] `pnpm build:server` 通过
- [ ] `pnpm test:smoke` 通过
- [ ] `pnpm verify:release` 通过

## 3. 提测检查清单

### 3.1 文档检查

- [ ] README 文档导航完整
- [ ] PRD 与当前实现范围一致
- [ ] 页面说明与实际交互一致
- [ ] API 文档与返回结构一致
- [ ] 数据模型文档与当前实现一致
- [ ] 测试用例文档可直接执行

### 3.2 功能完整性检查

- [ ] 首页功能完整
- [ ] 采访页功能完整
- [ ] 预览页功能完整
- [ ] 我的页面功能完整
- [ ] 接口错误返回可读

### 3.3 主链路检查

- [ ] 用户可从首页开始创作
- [ ] 用户可在采访页持续问答
- [ ] 用户可在达到阈值后生成预览
- [ ] 用户可在预览页返回继续补充
- [ ] 用户可在我的页面看到书稿结果

### 3.4 非功能检查

- [ ] 页面文案可理解
- [ ] 空状态完整
- [ ] 错误提示完整
- [ ] 加载态明确
- [ ] 页面跳转清晰
- [ ] 隐私政策与用户协议页面可直接打开
- [ ] 服务端 `GET /ready` 返回正常
- [ ] 高风险内容提交会被明确拦截

## 4. 验收清单

### 4.1 首页验收

- [ ] 有明确产品价值说明
- [ ] 有明确微信登录入口且登录成功后可进入主链路
- [ ] 首页可看到最近进度或最近书稿提示
- [ ] 有 4 个固定书籍类型
- [ ] 类型切换行为正确
- [ ] 开始创作成功后进入采访页
- [ ] 创建失败有清晰提示
- [ ] 首页无设置、查看更多或无定义菜单入口

### 4.2 采访页验收

- [ ] 可见书籍类型和会话 ID
- [ ] 可见当前问题
- [ ] 可见历史消息列表
- [ ] 可在语音播放和文字记录之间切换
- [ ] 每条采访记录可见时间信息
- [ ] 页面核心文案为简体中文
- [ ] 主录音按钮文案为 `开始录音`
- [ ] 点击一次可直接进入录音界面
- [ ] 录音界面显示 `正在录音` 和当前录音时长
- [ ] 录音界面可暂停和结束
- [ ] 录音界面无 `完成` 按钮
- [ ] 连续长录音会自动分段为约 1 分钟的小音频
- [ ] 自动分段不会明显从一句话中间切断
- [ ] 可跳过当前问题
- [ ] 至少 2 次回答后可生成预览
- [ ] 重新进入页面会话状态可恢复

### 4.3 预览页验收

- [ ] 可见标题
- [ ] 可见简介
- [ ] 可见章节目录
- [ ] 可见每章摘要
- [ ] 有“完整版待解锁”说明
- [ ] 可返回采访页继续补充

### 4.4 我的页面验收

- [ ] 可见书稿数量
- [ ] 可见书稿列表
- [ ] 列表按更新时间倒序
- [ ] 无数据时有空状态

### 4.5 接口验收

- [ ] 创建会话接口返回正确
- [ ] 会话详情接口返回正确
- [ ] 模拟转写接口返回正确
- [ ] 跳过问题接口返回正确
- [ ] 生成预览接口返回正确
- [ ] 书稿详情接口返回正确
- [ ] 我的书稿列表接口返回正确

## 5. 阻断提测问题定义

以下任一问题存在时，不允许提测：

- [ ] 首页无法创建会话
- [ ] 采访页无法提交回答
- [ ] 采访页无法推进到下一问题
- [ ] 达到阈值后仍无法生成预览
- [ ] 预览页无法展示核心内容
- [ ] 我的页面无法看到已生成书稿
- [ ] 核心接口返回结构与文档严重不一致
- [ ] 服务端频繁返回不可恢复错误
- [ ] 用户可以读取其他用户的会话或书稿
- [ ] 未登录情况下仍可访问受保护接口
